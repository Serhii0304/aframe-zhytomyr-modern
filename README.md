# А-ФРЕЙМ — сучасний сайт каркасного будівництва

Нова незалежна версія сайту: архітектурний лендінг українською, портфоліо, послуги, процес роботи, запитання та форма консультації. Дизайн починається зі сценарію мобільного клієнта.

- **Сайт:** https://serhii0304.github.io/aframe-zhytomyr-modern/
- **Оригінал збережено без змін:** https://github.com/Serhii0304/aframe-zhytomyr
- **Вихідний стан оригіналу:** `ff20b1871b71fbc515286d6f2c2fd399fd9ce423`

## Що змінилося

- Великий фотографічний перший екран, темно-зелена заливка, контрастні акценти й адаптивні макети. Локальний Manrope: основний текст 18–20 px на комп’ютері, 16–18 px на телефоні, збільшені підписи.
- Портфоліо одразу після першого екрана. Галерея з 11 фото, фільтрами, лайтбоксом, клавіатурою та свайпами.
- Фото з вихідного портфоліо відділені від прикладів і візуалізацій. Не додано вигаданих цін, відгуків, гарантій або термінів.
- Чотири постійні мобільні дії: звичайний дзвінок, Viber, Telegram, заявка. Враховано safe area та екранну клавіатуру.
- Вибір послуги переноситься у форму; перевіряються номер, обов’язкові поля й згода. Запит має 15-секундний тайм-аут, зрозуміле повідомлення помилки та телефон для альтернативного зв’язку.
- HTML попередньо генерується: текст, фото, FAQ, контакти та базова HTML-форма не залежать від завантаження React. Інтерактивні фільтри, меню та збільшення фото потребують JavaScript.
- WebP з точними `srcset`, локальні шрифти, відкладене завантаження другорядних фото, SEO, Open Graph, JSON-LD, sitemap і 404.
- Легка поява блоків і послідовні етапи: один IntersectionObserver, без обробника прокручування, циклів або нової бібліотеки. На телефоні коротші переходи без затримок; `prefers-reduced-motion`, навігація клавіатурою та відсутність JavaScript враховані. Постійні ефекти й розмиття мобільної панелі вимкнені.

Сайт не обіцяє автоматичний початок безкоштовного дзвінка: універсальної офіційної схеми для цього не підтверджено. Звичайний дзвінок завжди використовує `tel:`.

Telegram використовує офіційно задокументоване HTTPS-посилання на телефонний номер. Доступність контакту залежить від реєстрації номера й налаштувань приватності.

Документація: [Telegram phone-number links](https://core.telegram.org/api/links#phone-number-links), [Viber calls](https://help.viber.com/hc/en-us/articles/9030218421661-How-to-make-voice-and-video-calls-on-Rakuten-Viber).

## Форма: що має підтвердити власник

Збережено сервіс FormSubmit і адресу з оригіналу. Перед прийманням заявок власник пошти має переконатися, що FormSubmit активовано, та перевірити отримання реального листа. Розробницькі перевірки не надсилали тестових повідомлень замовнику. Успішна відповідь сервісу означає приймання запиту, а не підтвердження доставки в поштову скриньку.

Перевірте на справжніх Android та iPhone: відкриття Viber, наявність контакту, дзвінок із чату, Telegram і системний телефон. Комп’ютерна перевірка URI не замінює встановлені застосунки та реальні облікові записи.

## Редагування

- `lib/content.ts` — телефон, пошта, послуги, запитання, галерея.
- `lib/images.ts` — точні розміри фотографій і доступні варіанти.
- `components/landing.tsx` — блоки сторінки та інтерактивна поведінка.
- `app/globals.css` — палітра, типографіка, адаптивні правила.
- `app/layout.tsx` — метадані для пошуку та поширення посилань.
- `lib/contact.ts` — форматування номера й посилання застосунків.

Фотографії галереї успадковані з оригінального репозиторію; підтвердження прав на них залишається у власника. Вихідне маркування прикладів збережено. Дві нові ілюстрації А-фрейму й модульного будинку створені ШІ та позначені на сайті як концептуальні візуалізації. Вони не видаються за виконані об’єкти; походження та промпти записані в `docs/concept-image-provenance.json`. Manrope поширюється за SIL Open Font License, копія в `public/fonts/OFL.txt`.

## Локальний запуск і перевірка

Рекомендовано Node.js 24 LTS. Команда побудови враховує помилку завершення Node/libuv у Windows: після завершення Vinext дає нативним операціям 500 мс для закриття, зберігаючи справжній код помилки. Linux-публікація працює без цього обхідного рішення.

```sh
npm ci
npm run dev
```

```sh
npm run check
npm run build
```

Перевірки включають TypeScript, lint авторського коду, шість тестів телефонів, месенджерів, файлів та розмежування фото. Каталог `components/ui` і згенерований `hooks/use-mobile.ts` залишені без модифікацій; вони виключені з авторського lint. Нативний `img` застосовано свідомо для готових оптимізованих WebP на статичному хостингу. Нативна згода у формі забезпечує роботу з клавіатури навіть без JavaScript.

## Публікація

GitHub Actions автоматично перевіряє й публікує `main` через GitHub Pages. Налаштування Pages: **GitHub Actions**. Артефакт — `dist/client`; сервер Node для відвідувачів не потрібен.

Для Pages використовуються `BASE_PATH` та `SITE_URL` із workflow. Для хостингу в корені домену залиште `BASE_PATH` порожньою й задайте адресу в `SITE_URL`. Префікс зображень вбудовується під час компіляції, тому браузеру не потрібен `process.env`. Маніфест `.openai/hosting.json` належить окремому приватному перегляду Sites; секретів у ньому немає.

Не використовуйте `dist/server` як серверний продакшн-артефакт цього сайту. Сайт публікується статично, а серверні пакети використовуються лише під час розробки й побудови.
